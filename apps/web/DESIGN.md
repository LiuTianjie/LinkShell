# LinkShell Web: Linear 风格规范

所有页面共用一套规则。改页面时先读这份，再读 `AGENTS.md`。

## 版式

- 侧栏 232px，通顶，与应用底色（`--background`）同色，无右边框。主区是嵌入的圆角面板（`--plain`，1px `--separator` 边框，8px 圆角），外围留 8px。
- 没有全局顶栏。主区顶部是 44px 的 `.console-context`：左侧面包屑，右侧电脑、主题、帮助、连接设置。页面不要再自己画一条顶栏。
- 内容最大宽度 1040px，居中；左右内边距至少 20px。聊天和远程桌面可以占满。
- 页面标题 20px/600，副标题 13px 次级色。一页只有一个主按钮（靛蓝 `--accent`），其余用 `outline` 或 `ghost`。

## 字号、密度、控件

- 正文 13px，辅助 12px，最小 11px，只用于时间戳。不要再出现 10px。
- 控件高度统一 28px（按钮、输入、选择、标签页）。图标 16px，描边 1.65。
- 列表行高 40–44px，一行一条：图标、标题、次要信息（单行省略）、右侧元数据。行之间只用 1px 分隔线，悬停用 `--fill`。
- 状态用「圆点 + 文字」，不用填充色块。颜色只来自 `--running` / `--success` / `--warning` / `--danger` 等语义变量。
- 不要「卡片套卡片」。分组用小标题（12px/600，次级色）+ 分隔线；只有真正独立的对象（对话框、浮层、设置面板）才用边框容器。
- 阴影只用于浮层（菜单、对话框、预览小窗）。

## 颜色

- 只用 `theme.ts` 里的语义变量，不写十六进制。明暗两套都要看。
- 选中态用 `--sidebarAccent`（中性），不用主色。主色只给主按钮、焦点环、链接。

## 样式组织

- 样式放在 `src/styles/<模块>.css`：`base`（重置）、`common`（跨页组件）、`shell`（外壳）、`lists`（会话/项目列表）、`conversation`（聊天详情）、`screens`（远程桌面）、`resources`（文件/端口/Worktree）、`terminal`、`connect`（登录/配对）。
- 一个文件只放自己模块的类，类名以模块语义开头。禁止新增「polish」「overrides」之类的补丁文件，禁止用 `!important` 或提高选择器权重去压旧规则：直接改原规则，旧的就删。
- 优先用 shadcn 组件和 Tailwind 工具类；页面 CSS 只写版式。每个模块文件不超过 700 行。
- 页面里不再使用的类，当场删掉。

## 不能丢的

- 所有现有操作、快捷键、输入法处理、权限与能力检查、加载/错误/重连状态、iframe 隔离，改版前后一个不少。
- 改完跑 `pnpm --filter @linkshell/web build`、`lint`、`test`，并在浏览器里看明暗两套、窄屏（390px）、菜单与溢出。
