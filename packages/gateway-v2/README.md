# @linkshell/gateway-v2

The LinkShell v2 relay. It authenticates computers and devices by key, routes their
end-to-end encrypted frames (it can't read them), and brokers pairing by QR code or
six-digit code. `@linkshell/gateway` serves it at `/v2/connect`; it can also run alone.

Requires Node.js 22.13 or newer.
