## 验证与交付

原 23 项整批实现后统一验证：

- `pnpm build` 通过，包含 Mac 双架构 helper、Electron 原生模块、Web 和全部共享包；Windows 原生构建在 macOS 上按脚本跳过。浏览器布局收尾后另行通过 Web 最终构建。
- `pnpm typecheck`、Web/App lint 和 `git diff --check` 通过。
- 9 个受影响包共 **1,675 项测试通过，32 项因平台跳过**：wire 71、desktop 11、Windows 1（26 跳过）、Host 729（6 跳过）、gateway 44、client-core 186、CLI 139、Web 216、App 278。包含首条消息前配置应用与失败清理、权限续接及停止竞态、历史回放与旧响应、双设备改名同步、项目归组与同机连接、更新包下载和校验。
- 浏览器使用临时 Host/Gateway 和模拟 Agent，复用真实桌面 workspace 代理。已检查输入框及停止图标尺寸、左右侧栏拖拽/键盘/复位、文件内容滚动时目录及工具条位置；网页视觉与交互检查结果继续记录在 Web 验收文档中。

补充第 24 项：已核对本地 React Native 0.86.3 的 iOS 输入框复用和 placeholder 属性路径；邮箱框未设置行高，先前仅移除行高的处理未覆盖字距残留。App typecheck、lint 和差异检查通过。未新增或运行样式测试、未生成本地构建产物；仍需 iOS 发布构建反复从配对页返回登录页，检查聚焦、输入后清空以及重新进入时的占位文字。

仍需对应环境验收：Windows 安装器原位升级、重新打开及故障回滚；iPhone Duo 竖屏、键盘和前后台恢复；真实 Codex/Claude/ACP 权限行为及多台真机名称同步。本地浏览器、模拟 Agent 和编译结果不作为这些场景已通过的证明。

能力边界：Codex 无法原地修改运行中沙箱，因此同一 thread 自动续接以应用新权限；外部窗口独占运行会话无法可靠控制时明确提示不支持。新会话只提供 Agent 实际公开的选项，旧 Host 不虚构设置或同步成功。全部电脑项目视图按各机权限读取，手机初次索引最多 200 个项目与 200 条近期会话，历史在对应电脑继续加载。旧端别名在主机首次明确命名/重置前保留，不自动互相覆盖。

本次为源码修复，不包含发布或部署。本轮临时产物在验证结束后清理，原有构建输出和共享缓存保留。
