第 24 项的实现依据是 React Native 0.86.3 的 iOS 输入框复用和 placeholder 属性路径：邮箱框未设置行高，先前仅移除行高的处理未覆盖残留字距，因此普通单行输入显式归零字距。手机的最终设备矩阵、Windows CI 报告和最终统一检查结果仍待验收结束后补入。

能力边界：Codex 无法原地修改运行中沙箱，因此同一 thread 自动续接以应用新权限；外部窗口独占运行会话无法可靠控制时明确提示不支持。新会话只提供 Agent 实际公开的选项，旧 Host 不虚构设置或同步成功。全部电脑项目视图按各机权限读取，手机初次索引最多 200 个项目与 200 条近期会话，历史在对应电脑继续加载。旧端别名在主机首次明确命名/重置前保留，不自动互相覆盖。

本次为源码修复，不包含发布或部署。已结束的独立 Review/RPC/命名验收临时环境已清理；仍供手机和跨机验收使用的共享环境由主任务结束时统一清理。原有构建输出和共享缓存保留。
