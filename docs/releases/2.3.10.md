# 2.3.10 / CLI 0.10.10

## 改动

- 电脑上 Codex 桌面 App 发起的问题，在电脑上回答后，App 不再显示 `<send_user_message_question_reply>` 原文：气泡里显示灰色的问题（最多两行）和回答。
- 被 Codex 桌面 App 或独立 `codex` 占着的会话也显示模型、推理强度和权限（Host 从会话文件里最后一次 `turn_context` 读取）；这时从手机改设置会说明要在电脑上改，会话设置页同样提示并禁用。
- 输入框下方的设置不再横向滚动：合成一个入口（模型 · 推理强度，完全访问时显示橙色盾牌，计划 / 快速模式开着时有标记），点开是会话设置页。
- 去掉单独的命令按钮：输入 `/` 或从 + 菜单打开命令。
- Android：后台任务、会话设置这两个表单页顶部留出空间；只有已完成的任务时直接列出，不用再点“查看其他 N 个任务”。
