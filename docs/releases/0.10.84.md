# LinkShell 0.10.84 发布说明

远程桌面在打不通直连的网络里也能用视频看画面：官方网关新增 TURN 中继。另有 2026-10-30 使用反馈的第二轮补修。

0.10.83（cli 0.10.83、host 0.4.77、gateway 0.6.47、mac 0.1.40）只发布了 npm 包，没有桌面包、Homebrew 和网关部署，随即被 0.10.84 取代：补了下面「远程桌面全屏工具栏」一条。

## 远程桌面：TURN 中继

- 视频按这个顺序找路：先直连（局域网、穿透 NAT），直连不通走官方网关的 TURN 中继，视频仍连不上时才用原来的网关字节中转。中继仍是同一条 WebRTC 视频轨道，原生解码、码率自适应和低延迟都不变，比字节中转流畅得多。
- 中继服务部署在腾讯云节点（coturn，`deploy/turn/`）。网关给电脑签发临时凭证（`turn.credentials`），电脑登录网关时取一次，有效期过半再换，开屏幕时不用等。
- 经中继的画面码率上限 3 Mbit/s（网关 `TURN_MAX_KBPS`），电脑端识别出中继路径后自动限制；能直连时中继只有少量保活包。
- 经 TURN 中继或网关字节中转的画面，3 分钟没有任何操作（触摸、点击、滚动、按键、缩放）会断开，提示“长时间没有操作，画面已断开”，不会自动换另一条路径；点“重新连接”直接回到上次成功的路径。直连的画面不受限。电脑上 `LINKSHELL_SCREEN_IDLE_SECONDS` 调整（`0` 关闭），`LINKSHELL_TURN=off` 不用 TURN。
- 不影响没更新的客户端：旧版 App、旧版桌面端连到新版电脑时不用 TURN、也没有空闲断开，和以前一样。只有声明支持的新客户端（`turn=1`）才会拿到中继。
- 观看页加 `?ice=relay` 只走中继，用于在能直连的网络里实测 TURN。

## 桌面端与 CLI

- 打开会话时，输入框不再先被顶高 34px 再落回：桌面版不再在输入框下方显示「同步完成后可发送」，改成占位文字「正在同步会话，完成后可发送…」。
- 会话底部不再出现两行「正在运行」：命令自己的那一行已经在转圈时，底部只显示「本轮已进行 x 分 x 秒」，带标题的思考、等待回答等无法由上一行说明的状态仍完整显示。
- 菜单栏 / 托盘菜单恢复「检查更新…」，发现新版本后变成「更新到 x.y.z…」。Electron 版托盘菜单此前从未有过这一项（旧 Swift 弹窗有）。
- 远程桌面全屏工具栏：浅色主题下「控制中」「退出全屏」不再是深色字（工具栏始终是深色底，按钮自带的文字颜色盖过了它的样式）；悬停、打开菜单时也不再变暗；按钮文字不再折行。

## 已验证

- 本机真实 Mac App + 无头 Chrome + 本地 coturn：中继首帧 0.66 s，40 s 空闲限制在 42 s 断开且不换路径，重连 0.32 s，有操作时不断开，直连不受限；码率上限 400 时实测 392 kbit/s（同画面直连 1410）。
- 正式 coturn（110.40.187.233）公网实测：`relay→srflx` 路径首帧 2.28 s，约 790 kbit/s，空闲断开后重连 0.74 s。
