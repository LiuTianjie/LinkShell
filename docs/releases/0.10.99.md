# LinkShell 0.10.99

- 修复退出账号后，显式配置官方网关的电脑仍可能继承旧账号绑定的问题。退出会关闭本机账号连接，并尝试解除远端绑定；兼容旧 Host，网关未确认时明确提示。
- 改善受限网络下的登录和令牌续期，避免异常响应后重复消耗一次性令牌。
- 桌面安装包包含匹配版本的 CLI 与 Host；机器身份、配对记录和会话数据继续保留。

本次不更新官方网关服务。新增的持续会员复检默认关闭；既有客户端与线上 0.6.61 网关保持兼容。

Windows 安装器和便携包未签名，系统可能显示“未知发布者”或 SmartScreen 提示。macOS 安装包继续使用原 Developer ID、bundle ID 和更新签名。
