# LinkShell 0.10.85 发布说明

## Mac 原生远程桌面

- 保留 Electron 界面，恢复独立原生 WebRTC 接收与 VideoToolbox 硬件解码，解码画面通过 IOSurface Mach 端口直接交给窗口内的 Metal 视图。
- 像素不进入 JavaScript、Canvas 或 Chromium 视频播放器。原生鼠标、键盘和输入法经 DataChannel 发送。
- 复用最新帧 mailbox 和单个在途 GPU 提交；限制跨进程未释放帧，直到 GPU 完成后才允许解码器复用。拒绝交错到达的旧帧，关闭时由接收线程释放 Mach 端口，避免快速重连中的端口复用竞态。
- Intel Mac 优先 H.264，Apple silicon 优先 HEVC；只协商本机支持硬件解码的格式。macOS 13 起，独立发行 arm64 与 x64 包。

## 版本

CLI / 桌面 0.10.85；Mac helper 0.1.42；Host 0.4.79；Gateway 0.6.49。Wire 和移动 App 不变。

## 验证边界

本轮按用户要求执行代码 review、发布构建、架构与签名检查，不追加本地测试或 Intel 运行测试。前一轮的本机硬件解码、Metal 呈现、输入干运行及隐藏恢复结果仅覆盖当时构建；本次竞态修正和 Intel 兼容性结论来自代码检查和发布制品检查。Intel 真机、公网卡顿与稳定帧率仍未经过本轮实测。
