# 2.3.8

状态（2026-10-08）：[GitHub Release 2.3.8](https://github.com/LiuTianjie/LinkShell/releases/tag/v2.3.8) 已正式发布，包含 APK、AAB 和 IPA；iOS 2.3.8（20308）已成功上传 App Store Connect，等待 Apple 处理。仅更新 iOS / Android App，build number / versionCode 为 20308；Host、Mac 组件、wire 和 gateway 沿用现有版本。

## 改动

- Computer Use 小窗的收起、关闭按钮：可见圆底从 44 缩至 28，图标从 14 缩至 12；改为透明度较低的深色底和浅色图标，减弱黑色画面上的突兀感。
- 点击范围保持 44 × 44，按下时加强反馈。

- CUA 工具结果中的截图默认收起，展开对应工具记录后显示；其他工具图片和用户图片不变。

## 制品

制品源码为 `3f3f026`。仓库当前没有可用的 Mac runner，因此排队中的准备流水线已取消，改在本机按正式 `release.mjs --prepare-only` 流程完成干净 prebuild、签名与打包，并上传三个文件到 GitHub Release。用户随后明确授权 LinkShell 正式发布：已发布 Release，并复用同一归档成功上传 App Store Connect。标签触发的两条重复原生构建已取消。

`Prepare release artifacts` 已增加 `mobile_only` 模式，供 Mac runner 可用时仅构建并上传原生制品。按用户要求，本次没有追加功能验证或回归测试。iOS 上传成功，同时返回了部分预编译第三方 framework 缺少 dSYM 的警告；不影响此次上传，但对应崩溃帧的符号还原可能不完整。
