# LinkShell 0.10.93 发布说明

## Claude 会话可以打开插件页面（MCP App）

- 以前只有 Codex 会话能打开 StupidMirror 这类带页面的 MCP 工具，Claude 会话只能看到一个链接。现在电脑上的 LinkShell 读取 Claude 使用的同一份 MCP 配置（`~/.claude.json` 的全局和项目配置、已批准的项目 `.mcp.json`，去掉已停用的），在需要时自己连接这些服务。
- 会话右侧「+」→「插件和 MCP」列出可打开的页面；Claude 调用这类工具时，对话里那一行有「打开」按钮，页面也会自动打开。页面只能调用它所属服务里允许页面调用的工具。
- 「MCP 服务」面板显示 Claude 对 `/mcp` 的回答。
- 需要登录授权的服务（如 Figma）暂时打不开，LinkShell 不代为登录；启动慢的服务不会拖住菜单，最多等 4 秒。

## 桌面侧栏和对话

- **侧栏顺序固定。** 项目、会话和子会话按创建时间从新到旧排列，回复、审批和进度变化不再让列表跳动。新增「活跃会话」，收录运行中和等你处理的会话并显示当前进度。正在看的会话和它所在的项目始终留在侧栏里。
- **长对话更轻。** 收起的工具调用、思考过程和原始参数在第一次展开时才生成内容；一个 459 条的真实会话页面元素减少一半多。
- **展开上方的工具调用不再顶走正在看的内容**；展开动画中滚动、往上翻加载更早的历史时位置也保持不动。
- 消息下的时间和复制按钮不再遮住下一条回复。
- 输入框改为 Codex 式的一体圆角样式；登录对话框更简洁；会话设置面板全中文、不再截断。

## 稳定性

- Claude 被中断的工作流里，子任务不再一直显示「正在运行」。
- 发给 Agent 的图片先缩放到长边 2048 并重新压缩；单个附件上限统一为 20 MB。重试发送会复用已上传的文件。
- 电脑上的 LinkShell 异常退出后，下次启动会结束它留下的 Agent、MCP 服务和终端进程（进程号、命令行和启动时间都要对上）。
- Claude 可以停止后台任务；Codex 可以取消单个子代理、调整排队顺序。
- 连接、配对、网关和 Host 的报错与 Agent 设置项都显示为中文。

## 一套视觉规范

手机、桌面、网页控制台和官网改用同一套颜色与尺寸（`docs/design/visual-system.md`）：靛蓝表示操作与运行中，琥珀色表示等你处理，红色表示出错；浅色模式的次要文字对比度达到 4.5:1。
