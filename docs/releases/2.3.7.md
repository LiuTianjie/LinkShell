# 2.3.7 候选版

状态：候选版，尚未公开发布。最终发布由负责人执行。

## 本次内容

- Computer Use：Codex 会话内的独立电脑画面预览，支持低带宽 direct/relay 传输、拖动、放大、收起和重新打开；保留最后一帧。Mac 原生组件必须同步升级。
- iPhone Duo 与普通 iPhone：会话、输入框、导航和操作区适配可用空间。
- 命令与 Goal：可搜索的命令面板、独立入口、草稿保留；Codex 和 Claude 的持续目标按各自原生能力管理。
- 后台任务：Bash / Monitor / Codex 后台终端的列表、状态、输出和退出码；重连与重启恢复；Codex 单独停止任务。
- 双语 README、官网和使用文档同步；官网增加 Computer Use 示例和使用说明。

## 发布物与顺序

| 发布物 | 版本 | 说明 |
| --- | --- | --- |
| @linkshell/wire | 0.2.3 | 预览、命令、Goal 和任务协议 |
| @linkshell/mac | 0.1.1 | 含 ComputerPreview；在 Mac 上以原 Developer ID 签名 |

| iOS / Android App | 2.3.7 / 20307 | IPA、APK、AAB |

负责人最终发布时按 wire → mac → host → gateway → cli 顺序发布 npm 包，再分发 App。网关协议和数据库结构未变，不需要切换官方网关部署。Homebrew 安装入口需等 npm 发布可见后再更新，避免指向尚未公开的依赖。

`Prepare release artifacts` 仅构建、测试、打包并上传 Actions artifacts。Mac 包单独在本机签名打包；iOS 用 `--prepare-only` 导出 IPA。没有运行 npm publish、推送 App tag、创建公开 Release、上传 TestFlight 或部署 Pages。

## 已知边界

- Claude 的单任务停止接口仍依赖会改变子 Agent 格式的 AIR 能力，因此目前只开放查看。已核实 claude-agent-acp 0.84.0 和 0.87.0 都有此限制。
- Claude 的真实模型运行受本机 OAuth 授权失效限制；远程接管、后台任务和重启恢复已通过 Host / ACP / transcript 集成测试。
- 后台任务已通过真实 Codex 完成、完整输出和单任务停止隔离验证；iOS 模拟器已验证交互。Android 安装包构建与签名不等于设备交互验收。
- Computer Use 连续预览目前面向 macOS 上的 Codex，需要兼容的工具元数据和系统录屏权限。
