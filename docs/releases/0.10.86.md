# LinkShell 0.10.86 发布说明

## 桌面窗口焦点

- 修复打开或重新唤起桌面窗口时，“隐藏侧栏”按钮自动获得键盘焦点并弹出提示的问题。
- 没有活动控件时，焦点落在工作区容器；保留输入框、弹窗和手动选中控件的焦点，以及 Tab 键导航。

## 版本

CLI / 桌面 0.10.86；Mac helper 0.1.43；Host 0.4.80；Gateway 0.6.50。Wire 和移动 App 不变。

## 分发说明

macOS 提供 Apple silicon 与 Intel 独立安装包。Windows 安装器与便携包未签名，可能出现“未知发布者”或 SmartScreen 提示。
