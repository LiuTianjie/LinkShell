# LinkShell 0.10.102

- 全面优化桌面端工作台视觉与交互体验：新增侧边栏按工作区分组折叠、状态筛选及右键快捷操作，新增 `⌘K` 命令面板、System / Light / Dark 主题与 Comfortable / Compact 紧凑度切换；优化时间线工具卡片、计划卡、Diff 视图与长流式输出渲染，支持消息附件拖拽预览、右侧检查器内直接提交 Git 变更（`git.commit`）以及桌面端本地目录/编辑器一键打开（`desktop.openPath`）；保持工作台连接暖维持，并修复全屏远程桌面顶部菜单栏触发区与坐标映射。
- 强化协议完整性、网关转发与 Host 稳定性：Gateway 改为非阻塞式慢接收者断流，避免单个慢连接拖垮同机多设备心跳；补齐有界 Token / 会员校验缓存与限流；Host 完善会话创建幂等 `requestId`、确定性 `(before, beforeId)` 分页、`sessions.get` 查询、分片文件上传（保持对既有单次 20 MB 上传的兼容）、JSON-RPC 请求取消传播（`$/cancelRequest`）、SQLite 定期清理维护与空闲轮次块压缩（`compactTurnChunks`）。
- 同步更新配套版本的 Wire（`0.2.32`）、Mac helper（`0.1.57`）、Host（`0.4.96`）、Gateway（`0.6.65`）与 CLI（`0.10.102`），完全兼容既有的 `/v2/connect`、`linkshell-gateway-v2` 握手与线上 `/data/relay.db` 配对及账号绑定数据，确保线上老用户无缝自动重连。

Windows 安装器和便携包当前按未签名方式发布，系统可能显示“未知发布者”或 SmartScreen 提示；原生 ARM64、手机真机与公网屏幕性能不属于 CI 构建证明。macOS 安装包继续使用原 Developer ID、bundle ID（`com.bd.linkshell.host`）和 Sparkle 更新签名。
