# LinkShell 0.10.101

- 移除尚未正式开放的实验性编排界面入口，收敛工作区导航与命令面板层级。
- 移除会话输入框上方基于工作目录自动匹配的 `localhost` 端口提示条，避免同目录下无关本地进程端口产生误报干扰；端口预览继续通过专属端口面板按需打开。
- 同步更新配套版本的 Gateway（`0.6.64`）、Mac helper（`0.1.56`）、Host（`0.4.95`）与 CLI（`0.10.101`），保留既有机器身份、配对记录与会话数据。

Windows 安装器和便携包当前按未签名方式发布，系统可能显示“未知发布者”或 SmartScreen 提示；原生 ARM64、手机真机与公网屏幕性能不属于 CI 构建证明。macOS 安装包继续使用原 Developer ID、bundle ID（`com.bd.linkshell.host`）和 Sparkle 更新签名。
