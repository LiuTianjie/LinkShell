# 2.3.12 · CLI 0.10.13 · Gateway 0.6.6

## 改动

- Codex 桌面端提的问题（`request_user_input_async`）在手机和网页上显示为选项按钮，点选即回答，回答格式与桌面端相同。已在电脑上回答的问题标出选了哪项；用文字回答的只标为已回答。
- 网页端：回答显示为“问题 → 答案”，不再显示原始的 `<send_user_message_question_reply>` 文本。
- 网页端的电脑屏幕切换清晰度不再 404：观看页在网页的内嵌框架里时，由网页带着新宽度重新加载它；网页太旧时不显示这个选项。网页记住上次选的清晰度。
- App：全屏查看电脑屏幕时自动横屏，旋转按钮仍可切回竖屏。

## Claude 的提问

Claude 的 AskUserQuestion 是阻塞的。由 LinkShell 接管运行时（手机上发过消息）可以在手机上回答，这一点原来就支持。会话在终端或 Claude 桌面端里时，问题只能在电脑上回答：从外部回答需要往用户的 Claude 配置里加 hook（官方文档提供了 PreToolUse 的 `updatedInput.answers`），或者往终端里模拟按键。两种都没做。

## 验证

- `pnpm build`、`pnpm typecheck`、`pnpm lint`、`pnpm test` 通过（`claude-handoff.e2e.test.ts` 有一条原有的偶发失败）。
