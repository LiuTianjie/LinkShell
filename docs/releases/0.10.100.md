# LinkShell 0.10.100

- 新增智能保持唤醒（Smart / Always / Off）与电源状态采集，有活跃会话、终端或远程连接时阻止系统闲置休眠。
- 新增项目内 Git 变更对比与单文件回退、项目文件检索（`@file`）、远程剪贴板同步、屏幕隐私幕布与断开自动锁屏（Mac），以及 LinkShell Steward Agent（LSA）任务编排基础能力。
- 用量统计新增公开 API 单价估算价值与远程轮次 / 审批统计；新账户支持 7 天免费试用状态展示与邀请好友奖励查询，支持中 / 英 / 日界面语言切换。
- 网关支持会员试用状态校验并同步部署 `0.6.63`；桌面安装包包含配套版本的 CLI（`0.10.100`）、Host（`0.4.94`）与 Wire（`0.2.31`），保留既有机器身份、配对记录与会话数据。

Windows 安装器和便携包当前按未签名方式发布，系统可能显示“未知发布者”或 SmartScreen 提示；原生 ARM64、手机真机与公网屏幕性能不属于 CI 构建证明。macOS 安装包继续使用原 Developer ID、bundle ID（`com.bd.linkshell.host`）和 Sparkle 更新签名。
