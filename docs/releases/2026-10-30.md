# LinkShell 0.10.81 / App 2.3.58 发布说明

npm、Homebrew、Gateway、Android 与桌面制品已发布，iOS 已上传交接。最终桌面六个公开资产、官网与 Mac 更新 feeds 均已上线，下载、大小、摘要及正式 App 公网更新检查通过；本轮临时构建与验收资源已清理，并通过独立审计。当前证据与交付边界见[反馈修复报告](../feedback-2026-10-30.md)。

## 桌面端与 CLI 0.10.81

- 新建会话可在发送前选择 Agent 提供的模型、思考强度与权限；会话中的权限变更会实际应用，不支持的情况会明确提示。
- 修复历史会话打开时反复滚动、闪烁及快速切换后残留加载状态，让历史阅读位置更稳定。
- 集中查看多台电脑的项目，电脑名称随主机同步；自动创建的 Codex 聊天统一分组，同一电脑不再重复占据本机与远程列表。
- 桌面侧栏可调整宽度并拖动折叠，窄侧栏文字保持单行；文件目录与正文独立滚动，输入框、停止图标和明暗主题细节更清晰。
- macOS 更新前会确认 Host 已完成准备；准备失败时暂停更新、尝试恢复服务，并保留重试入口。
- 修复 macOS 重复打开时的重复 Dock 图标：仅窗口所属 GUI 显示 Dock 入口，重复打开与关窗重开复用同一实例，屏幕 helper 保持后台运行。
- 修复 Windows 模型列表和选择后的配置保持；补齐原生复制、剪切、粘贴与撤销菜单。
- Windows 增加应用内更新入口、下载校验与安装进度，安装失败时恢复原版本。Windows 安装器仍未签名，系统可能显示“未知发布者”或 SmartScreen 提示。

## App 2.3.58（20358）

- 返回 App 时保留原会话，恢复连接期间不再闪现登录、安装引导或错误的离线提示。
- 新会话增加模型、思考强度与权限选项；项目分组和自定义电脑名称与桌面端保持一致。
- 修复登录邮箱占位文字间距异常、输入框安全区和键盘收起后旋转贴底，安装引导增加桌面端下载入口。
- 优化麦克风、发送和停止按钮比例，以动态状态清楚显示 Agent 正在工作，并修复新一轮计时沿用上一轮起点的问题。

## Web 与 Gateway 0.6.45

- Google 登录在独立窗口完成授权，原页面自动接续登录；刷新后保留登录并重新发现电脑。
- 网页工作区同步获得会话设置、稳定历史阅读、多电脑项目、共享名称、可调整侧栏和独立文件滚动改进。
