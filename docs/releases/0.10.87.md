# LinkShell 0.10.87 发布说明

## 桌面窗口与菜单的焦点

- 修复从菜单栏图标、再次启动或登录启动后打开窗口时，“隐藏侧栏”按钮自动获得键盘焦点并弹出提示的问题。原因是 LinkShell 尚未成为前台应用时窗口被设为主窗口，macOS 像按 Tab 一样把焦点送进页面；现在显示窗口前先让页面成为第一响应者。0.10.86 的焦点占位处理针对的不是这个原因，已移除。
- 修复用鼠标在下拉菜单里选择后（例如切换主题），菜单按钮出现焦点框并重新弹出提示的问题。鼠标关闭菜单时焦点不再交还按钮；键盘关闭照旧交还。
- 提示只在键盘聚焦时随焦点弹出；切走再切回窗口时恢复的焦点不再弹出提示。

## 版本

CLI / 桌面 0.10.87；Mac helper 0.1.44；Host 0.4.81；Gateway 0.6.51。Wire 和移动 App 不变。

## 分发说明

macOS 提供 Apple silicon 与 Intel 独立安装包。Windows 安装器与便携包未签名，可能出现“未知发布者”或 SmartScreen 提示。
