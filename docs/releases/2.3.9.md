# 2.3.9 / CLI 0.10.9

状态：准备中，未正式发布。App build number / versionCode：20309。

## 改动

- iOS / Android 终端迁移到 Ghostty，支持终端回放、字号偏好、图片及交互能力。
- Host 增加带终端尺寸的逐帧记录与恢复协议；恢复历史时隔离终端查询回写。
- Grok ACP 打开会话时恢复已有登录缓存，减少重新认证失败。
- 新增独立网页客户端，支持账号与网关配对、会话及审批、动态命令 / Skills / MCP、文件、终端、屏幕与流式端口预览；交互组件采用 shadcn。

仅准备工作流运行构建、类型检查、lint、测试、npm 打包、Web 静态打包、Docker 构建与 /healthz 验证，不执行公开发布。

## 最终操作

npm 按 wire → host → gateway → CLI 顺序发布已核验的 tarball；使用 pnpm publish。
App 制品上传为草稿，正式 GitHub Release 与 App Store 分发由用户完成。
网页首次部署需要主站与隔离预览域名，不能将预览运行在账号页面同一来源。
