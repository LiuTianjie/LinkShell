# 2.3.9 / CLI 0.10.9

状态：npm、Docker、官方网关、GitHub Release 和 Homebrew 已发布；iOS 已上传 App Store Connect，TestFlight 可用状态及商店审核/发布状态尚待登录核对。App build number / versionCode：20309。

## 改动

- iOS / Android 终端迁移到 Ghostty，支持终端回放、字号偏好、图片及交互能力。
- Host 增加带终端尺寸的逐帧记录与恢复协议；恢复历史时隔离终端查询回写。
- Grok ACP 打开会话时恢复已有登录缓存，减少重新认证失败。
- Host 安装时修复它自己解析到的 node-pty spawn-helper 执行权限，避免独立安装或依赖未合并时打开终端失败。
- 新增网关内置网页客户端，支持账号与网关配对、会话及审批、动态命令 / Skills / MCP、文件、终端、屏幕与流式端口预览；交互组件采用 shadcn。
