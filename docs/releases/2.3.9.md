# 2.3.9 / CLI 0.10.9

状态：制品流水线通过，候选制品已准备，未正式发布。App build number / versionCode：20309。

## 改动

- iOS / Android 终端迁移到 Ghostty，支持终端回放、字号偏好、图片及交互能力。
- Host 增加带终端尺寸的逐帧记录与恢复协议；恢复历史时隔离终端查询回写。
- Grok ACP 打开会话时恢复已有登录缓存，减少重新认证失败。
- Host 安装时修复它自己解析到的 node-pty spawn-helper 执行权限，避免独立安装或依赖未合并时打开终端失败。
- 新增网关内置网页客户端，支持账号与网关配对、会话及审批、动态命令 / Skills / MCP、文件、终端、屏幕与流式端口预览；交互组件采用 shadcn。

## 人工发布顺序

1. 确认本次候选制品和校验和，按 wire → host → gateway → CLI 使用 `pnpm publish <tarball> --access public` 发布。
2. 将流水线导出的网关 Docker 镜像加载并推送版本标签 `nickname4th/linkshell-gateway:0.6.5`，再按既有 Luma 部署流程切换；这一步才会使新版网页在正式域名可见。
3. 确定端口预览的隔离来源后，配置对应 HTTPS 路由和 `WEB_PREVIEW_ORIGIN`。目前未配置，主网页可用，生产端口预览不可用。
4. 上传 IPA 到 App Store Connect，确认处理结果后自行决定 TestFlight / App Store 分发；GitHub 草稿的公开发布也由维护者执行。
5. npm 正式发布后运行 `./scripts/update-brew.sh 0.10.9` 更新 Homebrew 渠道。

请勿把构建成功、本机升级或草稿上传称为生产上线。
