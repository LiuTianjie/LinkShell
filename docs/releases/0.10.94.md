# LinkShell 0.10.94 发布说明

## LinkShell 并入 iTool 会员

- 官方网关现在属于 iTool 会员：月度 ¥9.9 包含 iTool 网站和 LinkShell，年度 ¥99 包含全部 iTool 产品。会员只在 itool.tech 用支付宝开通（`https://itool.tech/pro?from=linkshell`），用 LinkShell 的同一个账号登录即可。
- 激活码停用：所有兑换入口和链动小铺链接都已移除。已经兑换过激活码的账号已转为年度会员，不需要做任何事。
- Mac、Windows 桌面版和网页工作区：普通账户看到「开通 iTool 会员」按钮，在浏览器打开购买页；付款后回到窗口会自动刷新会员状态，也可以手动刷新。会员显示为「iTool 月度会员 / 年度会员」及 LinkShell 有效期。
- `linkshell login` 会说明账号是哪一档会员。
- 手机 App 和 Apple Watch 不提供购买，只显示一行「在电脑浏览器打开 itool.tech/pro 开通会员」；回到前台时刷新会员状态。
- 会员状态通过 itool.tech 的会员接口读取，在屏蔽 supabase.co 的网络里也能读到；接口暂时不可用时保留上一次的状态。
- 官方网关（0.6.58）改用 iTool 的会员接口判断电脑能否接入；查询本身失败时照旧放行。自建网关不受影响，仍然免费。
