# LinkShell 0.10.96 发布说明（App 2.3.62）

## 手机屏幕：画面节奏

- 屏幕观看页的「连接信息」里，清晰度下面新增「画面节奏」：默认「延迟优先」（每帧解码后立刻显示，最跟手）；可选「流畅优先」（接收端自适应缓冲），画面更均匀，Wi-Fi 下延迟约多 50 ms，适合只观看。与 Mac 桌面版的同名选项一致。
- iOS 仍走原生接收（WebRTC 解码 + Metal 显示）：选择流畅优先时，原生接收端在应答里拒绝 playout-delay 扩展。需要 App 2.3.62。
- Android 和 iOS 标准播放路径由观看页处理，随 Host 0.4.90 生效。
- 选择会保存在手机上；切换时以原来的播放方式重新连接画面。旧 App 不显示这个选项。
