# LinkShell 0.10.88 发布说明

## 桌面品牌图标

- 桌面标题栏使用带白色圆角底的完整应用图标，浅色和深色模式均与 Dock 图标保持一致。
- 包含 0.10.87 的桌面窗口与菜单焦点修复。

## 版本

CLI / 桌面 0.10.88；Mac helper 0.1.45；Host 0.4.82；Gateway 0.6.52。Wire 和移动 App 不变。

## 分发说明

macOS 提供 Apple silicon 与 Intel 独立安装包。Windows 安装器与便携包未签名，可能出现“未知发布者”或 SmartScreen 提示。
