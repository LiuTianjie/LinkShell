# LinkShell 0.10.82 发布说明

桌面端远程桌面重做后的发布。npm、Homebrew、Gateway（含官方网关部署）、Mac / Windows 桌面制品、官网与 Mac 更新 feeds 均已上线。移动端没有改动，不发版。

## 桌面端与 CLI 0.10.82

- Electron 桌面窗口（Mac 与 Windows）的远程桌面改为自带的接收端，不再套用 Host 的手机观看页：默认直接控制，鼠标、滚轮、键盘与中文输入直接发送，⌘ / Ctrl 在 Mac 与 Windows 之间互换。
- 清晰度跟随画面实际显示的设备像素，窗口调整或进入全屏后在同一连接上重新配置；全屏取到显示器原生宽度。
- 画面获得键盘时，菜单快捷键（⌘W、⌘Q、⌘H 等）交给远程电脑，⌃⌘F 留在本机退出全屏。
- 全屏：主进程记住页面最新的全屏意愿，每次进入 / 退出动画结束后再对齐，动画期间连续切换不再丢失。
- 去掉侧栏上方误显示的「跳到内容」；浏览器版的跳转链接只在键盘聚焦时出现。
- 浏览器里的网页工作台仍使用原观看页。技术细节见[屏幕技术架构](../v2/screen-realtime.md)的「桌面版接收端」。
