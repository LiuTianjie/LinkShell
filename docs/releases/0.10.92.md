# LinkShell 0.10.92 发布说明

## Mac 桌面版远程桌面：与手机对齐

- **切屏、清晰度、帧率不再重连。** 设置在现有连接上直接生效；切换显示器不再报错。离开屏幕页时暂停采集，两分钟内回来接着用。
- **帧率跟随本机显示器。** 按窗口所在显示器的刷新率（以及低电量、过热）限制在 30 / 60 / 120，接 60 Hz 外接屏时不再让对面编码 120 帧。
- **“随窗口”清晰度跟随窗口与全屏变化**，停稳后在原连接上重新取档。
- **失败自动恢复。** 可恢复的错误静默重试两次；直连或网络仍不通时，改用页面内接收端（可经加密中继）。
- **按住键与鼠标中键。** 对端为 Mac helper 0.1.49+ 时，修饰键、方向键、空格和 ⌘/⌃ 组合按键盘位置按下与松开：可以按住 ⇧/⌘ 点选、按住空格拖动画布、⌥ 悬停，方向键按住自动重复。文字仍走本机输入法。⌘Tab 等被本机系统先处理的快捷键仍到不了对端。
- **画面节奏选项。** 默认“延迟优先”（每帧解码后立刻显示）；可选“流畅优先”（接收端自适应缓冲），画面更均匀，但 Wi-Fi 下延迟约多 50 ms，适合只观看。
- 有画面时视频图层不透明，远程桌面开着时窗口不使用毛玻璃背景。

## 周期性短卡顿排查

- 逐帧打点排除了“发送端每秒读取统计”这一原因：停顿与统计读取的时间无关。
- 停顿主要来自编码之后的抖动；在 0/0 播放延迟下直接显示为停顿。Wi-Fi 的射频暂停会放大它。
- 自适应缓冲能消除大部分停顿，但类 Wi-Fi 抖动下中位延迟从 21 ms 升到 72 ms。复核了当初选择 0/0 的理由，结论仍成立，因此默认值不变，手机端不变。数据与工具见 `docs/v2/screen-realtime.md`、`apps/mac/tools/jitter-check.mjs`。

## 版本

CLI / 桌面 0.10.92；Mac helper 0.1.49；Host 0.4.86；Gateway 0.6.56。Wire 和移动 App 不变。

## 分发说明

macOS 提供 Apple silicon 与 Intel 独立安装包。Windows 安装器与便携包未签名，可能出现“未知发布者”或 SmartScreen 提示。

## 验证范围

- Web 单测（会话策略）、Swift 全量测试、原生回环（拒绝 playout-delay 扩展、切换显示器后继续出帧）、`input-check.mjs`（按住键、中键、离开时释放，dry-run）。
- 开发版 Electron + 临时 Host 回环：原生 H.265 硬件解码 + Metal；本机 60 Hz 显示器时请求帧率为 60；改清晰度、离开屏幕页再返回均未重新协商。
- 未覆盖：真实键盘在 Electron 窗口内的按住键交互、Intel 真机、手机与公网弱网。
