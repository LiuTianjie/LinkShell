# LinkShell 0.10.103

- 桌面端工作台：检查器内直接编辑并原子保存文件（Host 新增 `fs.write`，拒绝覆盖编辑器未见过的修订，不经符号链接写入），未保存草稿跨会话保留；时间线选中文字可「在侧边对话中提问」或「在回复中引用」；侧边问答（Codex `/side`、Claude Code 与 Grok `/btw`）和 Steer 按代理实际能力提供，不支持时明确显示「中断并发送」；插件/MCP 应用面板按代理 `mcpApps` 能力显示；全部界面文案、原生菜单与通知走中/英/日词典；窗口失焦时会话需要处理会发系统通知，窗口位置按可见显示器恢复。
- 融合模式：会话凭据只经 0600 本地套接字传递；「断开融合」优先于仍在等待的启动或重连；意外断线按退避自动重连；修复开启 Clash / Surge 等代理 TUN 模式时直连探测误选不可达地址（现在要求远端返回 TLS 应答，且不再通告 `198.18.0.0/15`），握手失败不再误报为「凭据已失效」；运行中应用卡片保持名称与窗口数可读。
- 远程屏幕：被其他设备接手或空闲结束后不再自行抢回画面；双击/三击、恢复期间松开的按键、Windows AltGr 字符、F11 与 ⌃⌘F 均正确处理；遮挡层不再盖住侧边栏抽屉、下拉选择与短提示；屏幕与融合模式的提示按界面语言显示。
- 同步更新配套版本的 Wire（`0.2.33`）、Mac helper（`0.1.58`）、Host（`0.4.97`）、Gateway（`0.6.66`）与 CLI（`0.10.103`），完全兼容既有的 `/v2/connect`、`linkshell-gateway-v2` 握手与线上 `/data/relay.db` 配对及账号绑定数据。

Windows 安装器和便携包当前按未签名方式发布，系统可能显示“未知发布者”或 SmartScreen 提示；原生 ARM64、手机真机与公网屏幕性能不属于 CI 构建证明。macOS 安装包继续使用原 Developer ID、bundle ID（`com.bd.linkshell.host`）和 Sparkle 更新签名。
