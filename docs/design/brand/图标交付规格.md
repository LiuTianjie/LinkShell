# LinkShell 品牌图标交付规格

范围：只替换 LinkShell 自身的品牌图标，包括 App、菜单栏、网页 Logo、favicon、启动页和分享图。不包含设置、返回、终端等功能图标，也不修改 Codex、Claude 等第三方标识。

请交付可编辑矢量源文件（Figma / SVG），另附以下 PNG 导出。色彩使用 sRGB；PNG 不要附加空白边框。图形、留白和背景应分层，以便适配系统裁切。先定一个主标，再制作小尺寸简化版和单色版，不必沿用现有终端外形。

## 给设计师的交付清单

| 用途 | 交付尺寸 | 设计要求 |
|---|---|---|
| iOS 主 App 图标 | 1024 × 1024 PNG | 不透明、满画布；不要预先画圆角，系统裁切。另交分层矢量源稿。 |
| macOS Dock / Finder / 权限窗口 | 1024 × 1024 PNG + SVG | 独立 Mac 版，允许透明外缘；内部构图在 16 / 32 px 下仍可识别。工程生成 ICNS：16、32、64、128、256、512、1024 px。 |
| macOS 菜单栏 | SVG 或矢量 PDF；18 × 18、36 × 36 PNG | 本项目显示框为 18 pt。单色实心形状 + 透明背景，不带底板、渐变、彩色点或文字；系统自动适配亮暗。按原尺寸检查清晰度。 |
| Android 自适应图标前景 | 1024 × 1024 透明 PNG | 主体放在中心安全区，约直径 626 px（66/108）；边缘留空间供系统遮罩和动效，不预画圆角或系统外阴影。 |
| Android 自适应图标背景 | 1024 × 1024 不透明 PNG，或明确纯色值 | 满画布，与前景分离。 |
| Android themed icon | 1024 × 1024 透明 PNG + SVG | 只含单色轮廓/形状，以透明度定义图形，不含品牌背景。 |
| Apple Watch | 1024 × 1024 PNG | 当前共用手机主图；可交独立适配稿，考虑圆形裁切，避免细字。 |
| 启动页 Logo | 1024 × 1024 透明 PNG，亮/暗各一份 | 当前以 120 pt 宽 contain 显示；背景单独给颜色，不把整屏背景烘焙进 Logo。 |
| 产品内 / 网页品牌标 | SVG + 240 × 240、480 × 480 透明 PNG | 无文字图形，提供亮底和暗底版本；在 24、40、56、72 px 下都检查。 |
| 网站 favicon | SVG、16 × 16、32 × 32、48 × 48 PNG；可附 ICO | 专门简化小尺寸细节，不能只把复杂图机械缩小。 |
| iOS 网页主屏幕图标 | 180 × 180 PNG | 不透明，不预画圆角。 |
| PWA 安装图标 | 192 × 192、512 × 512 PNG；另交 512 × 512 maskable PNG | maskable 必须满底，核心图形在中心直径 80% 的圆内。 |
| 网站 / README Logo | SVG + 200 × 200、400 × 400 PNG | 网站头部 28 px、底部 22 px，README 96 px；保证深浅背景可读。 |
| 社交分享卡 | 1200 × 630 PNG | 新品牌标 + LinkShell 名称，保留可编辑文字和排版；这不是正方形图标。 |

最小交付集合：主图、Mac 图、菜单栏单色图、Android 三层图、亮暗品牌标、favicon、PWA 图、分享卡。尺寸变体可由工程批量导出，不需要每个尺寸重新设计。

## 当前文件与使用位置

| 当前资源 | 当前像素 | 使用位置 / 替换方式 |
|---|---|---|
| `apps/client/assets/icon.png` | 1024 × 1024 | Expo iOS / 默认 App icon；Mac `build-app.mjs` 生成 ICNS；Watch 插件复用。Mac 独立稿需新增独立资源，避免继续共用手机稿。 |
| `apps/client/assets/android-icon-foreground.png` | 512 × 512 | Android adaptive foreground，配置见 `apps/client/app.config.*`。 |
| `apps/client/assets/android-icon-background.png` | 512 × 512 | Android adaptive background。 |
| `apps/client/assets/android-icon-monochrome.png` | 512 × 512 | Android themed icon。 |
| `apps/client/assets/splash-icon.png` | 1024 × 1024 | Expo splash，imageWidth=120；当前背景浅色 #F2F2F7、深色 #000000。 |
| `apps/client/assets/mark.png` | 240 × 240 | 手机账号页 72 pt；Web 欢迎页 56 px；Web 工作区 24 px。 |
| `apps/client/assets/favicon.png` | 48 × 48 | Expo web favicon。 |
| `apps/web/public/favicon.png` | 240 × 240 | 独立 Web 客户端浏览器页签。 |
| `docs/assets/adaptive-icon.png` | 200 × 200 | README / README_CN，显示 96 px。 |
| `docs/site/assets/adaptive-icon.png` | 200 × 200 | 官网 Logo、当前 favicon、apple-touch-icon；应按上表拆成对应资源。 |
| `docs/site/assets/og.png` | 1200 × 630 | 官网社交分享预览。 |
| `apps/mac/Sources/LinkShell/DesktopStatusIcon.swift` | 18 pt 矢量绘制 | 菜单栏临时单色标；新稿到位后改为模板资源。 |
| `apps/mac/build/LinkShell.app/Contents/Resources/AppIcon.icns` | 构建生成 | Finder / Dock / 权限窗口 / 桌面侧栏（40 pt）/ 菜单弹窗（38 pt）；不要直接编辑构建产物。 |

官网多语言页面由 `scripts/build-site-pages.py` 生成，换源图与模板后统一生成。当前 webmanifest 把 200 px 图声明成 1024 px 且共用 any/maskable；接入新图时同时修正为实际尺寸与独立 maskable 资源。

宣传截图、视频和安装说明截图中的旧 Logo 属于已经烘焙的内容，需要在品牌资源替换完成后重新截图/渲染，不能靠替换 PNG 自动更新。

## 验收

- 主图在手机主屏幕、Mac Dock、网页页签和菜单栏原尺寸预览。
- 亮色、深色和系统选中状态均清楚；菜单栏必须使用 template 着色。
- Android 检查圆形、圆角矩形、异形遮罩与单色主题。
- 交付文件命名区分 `app-ios`、`app-mac`、`menubar-template`、`adaptive-foreground/background/monochrome`、`brand-light/dark`，不要把圆角、底板和透明版混用。

平台依据：[Expo App 配置](https://docs.expo.dev/versions/v57.0.0/config/app/)、[Expo 启动页](https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/)、[Android 自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)、[Apple App icon 配置](https://developer.apple.com/documentation/xcode/configuring-your-app-icon)、[NSImage template](https://developer.apple.com/documentation/appkit/nsimage/istemplate)、[PWA maskable 安全区](https://web.dev/articles/maskable-icon)。18 pt、120 pt 和网页显示尺寸是本项目的当前实现尺寸。
