在手机上用 Codex。

Codex 留在电脑上跑，终端和手机同时在线。进度、改动和请求实时到手机，在 iPhone、Android 或 Apple Watch 上批准、插话，哪一端都能接着干。

终端和手机，同时在线

用 linkshell codex 打开的终端和手机共用同一个会话：任何一端都能发消息、打断、审批。普通 codex 和 Codex 桌面 App 里开的会话，手机上也能跟进。

$ linkshell codex
# 参数原样传给 codex

手机上也能用 Computer Use

在手机上让 Codex 操作电脑里的浏览器和桌面应用，画面在会话浮窗里实时预览。边看边聊，随时补充要求。浮窗可以拖动、放大或收起。（目前支持 macOS 上的 Codex）

不用打开 App，锁屏和手表上就能批准

实时活动在锁屏和灵动岛上显示进度；Codex 要权限时，卡片上直接给出「拒绝」和「允许」。Apple Watch 上也能看会话、回请求、发一句短消息。

实时活动需要 iOS 16.2 及以上，卡片上的按钮需要 iOS 17；手表 App 需要 watchOS 10 及以上。

/compact、/review、/init 和你的 skills 都能在手机上用。
后台命令
查看状态和输出，单独停掉其中一个任务。
回答提问，切换计划模式
回答 Codex 的提问，包括桌面版的异步提问；计划模式在手机上直接切换。
登录方式照旧
ChatGPT 登录、API Key 或自定义提供商（包括 CC Switch 管理的）都能用。

代码和 Codex 都留在你的电脑上

端到端加密
X25519 交换密钥，每一帧用 XChaCha20-Poly1305 加密。网关只转发密文。
用你自己的 Codex 登录
Codex 以你的用户身份、用它自己的登录运行，LinkShell 不经手账号和密钥。
不用同一个 Wi-Fi
手机经网关连进电脑，不用开放端口；网关用官方的或自建的都行。

三步开始

在电脑上安装

Mac 和 Windows 可以下载桌面 App，自带 CLI；macOS 和 Linux 也可以装 CLI，需要 Node.js 22.13 或更新版本。

下载桌面 App

$ npm i -g linkshell-cli
# 或
$ brew install LiuTianjie/linkshell/linkshell
$ linkshell setup

连接手机

官方网关：开通 iTool 会员后，电脑和 App 登录同一账号，电脑自动出现。自建网关：配对一次，扫码即可。

# iTool
$ linkshell login
# 自建网关
$ docker run -d -p 8787:8787 -v linkshell-gateway:/data nickname4th/linkshell-gateway
$ linkshell host --gateway wss://gw.you
$ linkshell pair

开始工作

$ linkshell codex

常见问题

手机要和电脑连同一个 Wi-Fi 吗？

不用。手机经网关连到电脑，在外面用蜂窝网络也行，也不用开放端口。

Codex 的账号和 API Key 会经过 LinkShell 吗？

不会。Codex 用电脑上已经登录的那一份运行，LinkShell 不经手账号和密钥。

能在手机上让 Codex 操作电脑吗？

能。用 Computer Use 让 Codex 操作电脑上的浏览器和桌面应用，画面在会话浮窗里实时预览。目前支持 macOS 上的 Codex。

不打开 App 能批准请求吗？

能。iPhone 锁屏的实时活动带「拒绝」和「允许」按钮（iOS 17 及以上），Apple Watch 上也能回复请求（watchOS 10 及以上）。
