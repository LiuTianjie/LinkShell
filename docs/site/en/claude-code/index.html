Every step, live

Replies stream in word by word. What it read, changed and ran updates live, with a diff for every file, alongside its plan, sub-agents and background commands.

Approve from the Lock Screen or your wrist

A Live Activity keeps Claude's progress on the Lock Screen and in the Dynamic Island; when it asks for permission, the card carries Deny and Allow. On Apple Watch you can follow sessions, answer requests and send a short reply.

Live Activities need iOS 16.2 or later, and buttons on the card iOS 17. The watch app needs watchOS 10 or later.

Cut in while it is busy

Messages sent mid-turn wait in a queue: reorder them, take one back to rewrite, or send it now, straight into Claude's running turn. A turn running on the computer can be stopped from the phone.

Hand it between terminal and phone

Start it with linkshell claude and you get Claude's own UI at your desk. A message from the phone takes over; any key at the computer takes it back, context intact. Sessions from a plain claude or the Claude desktop app can be followed too.

$ linkshell claude
# arguments pass through to claude
$ linkshell claude --resume

Done? Open the Mac's desktop

When Claude is done, open the computer's actual desktop on the phone to check a page, work in the editor or close a dialog. Or open a terminal, or the computer's localhost, right on the phone. (Full control on macOS 13 or later.)

Your code and Claude Code stay on your computer

End-to-end encrypted
Keys are agreed with X25519 and every frame is sealed with XChaCha20-Poly1305. The gateway relays ciphertext only.
Your own Claude Code sign-in
Claude Code runs as your user with its own sign-in. LinkShell never handles your accounts or API keys.
No shared Wi-Fi needed
The phone reaches the computer through a gateway with no open ports: the official one or your own.

Three steps

Install on your computer

On Mac or Windows, the desktop app brings its own CLI. On macOS or Linux you can install the CLI instead, with Node.js 22.13 or newer.

Download the desktop app

$ npm i -g linkshell-cli
# or
$ brew install LiuTianjie/linkshell/linkshell
$ linkshell setup

Connect your phone

Official gateway: with an iTool membership, sign in on the computer and in the app with the same account, and the computer just appears. Own gateway: pair once with a QR code.

# iTool
$ linkshell login
# your own gateway
$ docker run -d -p 8787:8787 -v linkshell-gateway:/data nickname4th/linkshell-gateway
$ linkshell host --gateway wss://gw.you
$ linkshell pair

Get going

$ linkshell claude

Questions

Does my phone need the same Wi-Fi as the computer?

No. The phone reaches the computer through a gateway, over cellular too, with no open ports.

Does LinkShell see my Claude account or API key?

No. Claude Code runs with the sign-in already on your computer; LinkShell never handles accounts or keys.

Can I approve a permission request without opening the app?

Yes. The Live Activity on the iPhone Lock Screen carries Deny and Allow (iOS 17 or later), and Apple Watch can answer requests too (watchOS 10 or later).

Does it work on Android?

Yes. The Android APK is on GitHub Releases, and there is a browser client too.
