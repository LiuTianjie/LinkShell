Three steps to your computer

On Mac or Windows, download the desktop app. The CLI supports macOS / Linux with Node.js 22.13 or newer.

Install and start

Mac · Apple Silicon Mac · Intel

macOS 13 or later: drag it into Applications, open it and sign in, then turn on Screen Recording and Accessibility in its Settings. The app brings its own CLI, Host and Node, and updates them together.

Windows · Installer Windows · ZIP

Windows 10 1809+ / Windows 11 x64: includes CLI, Host and Node, with the same workspace as Mac for conversations, terminals, files and port previews. The workspace requires Microsoft Edge WebView2 Evergreen Runtime. Packages are unsigned and may show unknown-publisher or SmartScreen prompts.

On Linux, or if you prefer the command line: install the CLI and run the setup once. It starts LinkShell in the background, takes you to the two permissions the screen needs, and connects your phone.

$ npm i -g linkshell-cli
$ linkshell setup

Without npm, install it with Homebrew or the install script:

$ brew install LiuTianjie/linkshell/linkshell
# or
$ curl -fsSL https://liutianjie.github.io/LinkShell/install.sh | sh

Connect your phone

Pro: sign in on the computer and in the app with the same account; the computer just appears. Own gateway: pair once with a QR code.

# Pro
$ linkshell login
# your own gateway
$ linkshell host --gateway wss://gw.you
$ linkshell pair

Get going

Start a session on the phone, or launch agents from your terminal like this to hand them over any time.

$ linkshell claude
$ linkshell codex
