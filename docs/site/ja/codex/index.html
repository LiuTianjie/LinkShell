Codex を、iPhone から。

Codex はパソコンで動かしたまま、ターミナルとスマホの両方から同時に操作できます。進み具合の確認、リクエストの承認、実行中のターンへの指示は、iPhone・Android・Apple Watch から。

ターミナルとスマホを同時に

linkshell codex で開いたターミナルとスマホは同じセッションを共有し、どちらからでもメッセージの送信、中断、承認ができます。通常の codex や Codex デスクトップアプリで開いたセッションも、スマホから追えます。

$ linkshell codex
# 引数はそのまま codex に渡ります

Computer Use もスマホから

スマホから Codex に、パソコンのブラウザやデスクトップアプリを操作させられます。操作の様子は会話の上の小さなウィンドウでライブ表示され、見ながら指示を足せます。ウィンドウは動かす、拡大する、たたむことができます（現在は macOS の Codex に対応）。

ロック画面とApple Watch で承認

ライブアクティビティがロック画面と Dynamic Island に進み具合を表示します。Codex が許可を求めると、カードに「拒否」「許可」ボタンが出ます。Apple Watch でもセッションを確認し、リクエストに応答し、短い返信を送れます。

ライブアクティビティは iOS 16.2 以降、カード上のボタンは iOS 17 以降、Apple Watch アプリは watchOS 10 以降で使えます。

Codex の機能をスマホでも

作業中でも指示を送れる
作業中に送ったメッセージはキューに入り、順番の入れ替えや取り消し、実行中のターンへの即時送信ができます。ターンはスマホから止められます。
/side で横から質問
読み取り専用の一時的なフォークで、やり取りはセッションに残りません。
/goal で目標を保つ
設定、一時停止、再開、クリアができ、トークンの予算も決められます。
スラッシュコマンドとスキル
/compact、/review、/init やあなたのスキルをスマホから使えます。
バックグラウンドのコマンド
状態と出力を確認し、タスクを個別に止められます。
質問への回答とプランモード
デスクトップアプリの非同期の質問も含め、Codex の質問に答えられます。プランモードはスマホの設定で切り替えます。
ログイン方法はそのまま
ChatGPT でのログイン、API キー、カスタムプロバイダ（CC Switch で管理しているものを含む）に対応します。

コードも Codex もパソコンの中に

エンドツーエンド暗号化
X25519 で鍵を交換し、すべてのフレームを XChaCha20-Poly1305 で暗号化します。ゲートウェイが中継するのは暗号文だけです。
Codex のログインはそのまま
Codex はあなたのユーザーとして、自身のログインで動きます。LinkShell がアカウントや API キーに触れることはありません。
同じ Wi-Fi でなくても
スマホはゲートウェイ経由でつながるので、ポートを開ける必要はありません。公式のゲートウェイでも、自分で立てたものでも使えます。

3 ステップで始める

パソコンにインストール

Mac と Windows では、CLI 入りのデスクトップアプリを使えます。macOS と Linux では CLI だけでも使えます（Node.js 22.13 以降）。

デスクトップアプリをダウンロード

$ npm i -g linkshell-cli
# または
$ brew install LiuTianjie/linkshell/linkshell
$ linkshell setup

スマホをつなぐ

公式ゲートウェイ：新規アカウントは 7 日間無料トライアル付き（カード不要）。パソコンとアプリで同じアカウントにログインすると、パソコンが自動で表示されます。自前のゲートウェイ：QR コードで一度ペアリングするだけです。

# iTool (7-day free trial)
$ linkshell login
# 自前のゲートウェイ
$ docker run -d -p 8787:8787 -v linkshell-gateway:/data nickname4th/linkshell-gateway
$ linkshell host --gateway wss://gw.you
$ linkshell pair

使い始める

$ linkshell codex

よくある質問

スマホとパソコンは同じ Wi-Fi につなぐ必要がありますか？

いいえ。スマホはゲートウェイ経由でつながるので、外出先のモバイル回線でも使えます。ポートを開ける必要もありません。

Codex のアカウントや API キーは LinkShell を経由しますか？

いいえ。Codex はパソコンでログイン済みのものをそのまま使います。LinkShell がアカウントやキーを扱うことはありません。

スマホから Codex にパソコンを操作させられますか？

はい。Computer Use を使うと、Codex がパソコンのブラウザやデスクトップアプリを操作し、その様子が会話の上のウィンドウにライブで表示されます。現在は macOS の Codex に対応しています。

アプリを開かずにリクエストを承認できますか？

はい。iPhone のロック画面のライブアクティビティに「拒否」「許可」ボタンが出ます（iOS 17 以降）。Apple Watch からもリクエストに応答できます（watchOS 10 以降）。

料金はかかりますか？

ゲートウェイを自分で立てれば（コマンド 1 つか Docker）、全機能を無料で使えます。公式ゲートウェイは新規登録で 7 日間無料トライアル（カード不要）がつき、その後は iTool メンバーシップ（海外カード US$3.19/月・US$26.49/年、Alipay ¥9.9/月・¥99/年）で利用できます。友だち招待で双方に 14 / 30 日間が付与されます。
