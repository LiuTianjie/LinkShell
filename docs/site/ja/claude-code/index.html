Claude Code を、iPhone から。

Claude Code はパソコンで動かしたまま。返信や変更、権限リクエストがすぐにスマホに届き、iPhone・Android・Apple Watch からワンタップで承認できます。実行中のターンにメッセージを送ることもできます。

iPhone 版を入手 Android APK パソコンの準備
Claudeweather-appたった今
テストを実行して、スタイル変更の影響を確認

承認が必要です

npm test

パソコンで npm test を実行中… 42 件のテストに合格。Claude は作業を続けます 拒否しました。Claude は別の方法を試します

スマホに届くリクエストはこんな形です。タップして試せます。

作業の様子をリアルタイムで

返信は一文字ずつ表示され、読んだファイル、変更、実行したコマンドもその場で更新されます。ファイルごとの差分、プラン、サブエージェント、バックグラウンドのコマンドも確認できます。

ロック画面とApple Watch で承認

ライブアクティビティがロック画面と Dynamic Island に進み具合を表示します。Claude が許可を求めると、カードに「拒否」「許可」ボタンが出ます。Apple Watch でもセッションを確認し、リクエストに応答し、短い返信を送れます。

ライブアクティビティは iOS 16.2 以降、カード上のボタンは iOS 17 以降、Apple Watch アプリは watchOS 10 以降で使えます。

作業中でも指示を送れる

作業中に送ったメッセージはキューに入ります。順番を入れ替えたり、取り消して書き直したり、すぐに送って Claude の実行中のターンに加えたりできます。パソコンで実行中のターンをスマホから止めることもできます。

ターミナルとスマホで引き継ぐ

linkshell claude で起動すると、パソコンでは Claude 本来の画面のまま使えます。スマホからメッセージを送ると操作が移り、パソコンで任意のキーを押すと戻ります。文脈はそのままです。通常の claude や Claude デスクトップアプリで開いたセッションも、スマホから追えます。

$ linkshell claude
# 引数はそのまま claude に渡ります
$ linkshell claude --resume
/btw で横から質問
実行中のターンを止めずに質問でき、やり取りはセッションに残りません。
サブエージェントとワークフロー
Claude のワークフローをフェーズごとに追い、各サブエージェントの会話とツールの結果を開けます。
質問への回答とプランモード
Claude の質問にスマホから答えられます。プランモードは権限モードの一つとして切り替えられます。
スラッシュコマンドとスキル
/ を入力すると、Claude のコマンドとあなたのスキルが一覧で出ます。
バックグラウンドのコマンド
Bash や Monitor のタスクの状態と出力を確認できます。
フォークと worktree
どの返信からでも新しいセッションに分岐でき、新しい git worktree にも置けます。

終わったら、Mac のデスクトップで確認

Claude の作業が終わったら、パソコンの実際のデスクトップをスマホで開き、ページを確かめたり、エディタを操作したり、ダイアログを閉じたりできます。ターミナルや、パソコンの localhost をスマホで開くこともできます（フル操作は macOS 13 以降）。

コードも Claude Code もパソコンの中に

エンドツーエンド暗号化
X25519 で鍵を交換し、すべてのフレームを XChaCha20-Poly1305 で暗号化します。ゲートウェイが中継するのは暗号文だけです。
Claude Code のログインはそのまま
Claude Code はあなたのユーザーとして、自身のログインで動きます。LinkShell がアカウントや API キーに触れることはありません。
同じ Wi-Fi でなくても
スマホはゲートウェイ経由でつながるので、ポートを開ける必要はありません。公式のゲートウェイでも、自分で立てたものでも使えます。

3 ステップで始める

パソコンにインストール

Mac と Windows では、CLI 入りのデスクトップアプリを使えます。macOS と Linux では CLI だけでも使えます（Node.js 22.13 以降）。

デスクトップアプリをダウンロード

$ npm i -g linkshell-cli
# または
$ brew install LiuTianjie/linkshell/linkshell
$ linkshell setup

スマホをつなぐ

公式ゲートウェイ：iTool メンバーシップを有効にし、パソコンとアプリで同じアカウントにログインすると、パソコンが自動で表示されます。自前のゲートウェイ：QR コードで一度ペアリングするだけです。

# iTool
$ linkshell login
# 自前のゲートウェイ
$ docker run -d -p 8787:8787 -v linkshell-gateway:/data nickname4th/linkshell-gateway
$ linkshell host --gateway wss://gw.you
$ linkshell pair

使い始める

$ linkshell claude

よくある質問

スマホとパソコンは同じ Wi-Fi につなぐ必要がありますか？

いいえ。スマホはゲートウェイ経由でつながるので、外出先のモバイル回線でも使えます。ポートを開ける必要もありません。

Claude のアカウントや API キーは LinkShell を経由しますか？

いいえ。Claude Code はパソコンでログイン済みのものをそのまま使います。LinkShell がアカウントやキーを扱うことはありません。

アプリを開かずに権限リクエストを承認できますか？

はい。iPhone のロック画面のライブアクティビティに「拒否」「許可」ボタンが出ます（iOS 17 以降）。Apple Watch からもリクエストに応答できます（watchOS 10 以降）。

Android でも使えますか？

はい。Android 版の APK は GitHub Releases から入手できます。ブラウザ版もあります。

料金はかかりますか？
