自建网关Self-host a gateway

# 或 Dockeror Docker

常见问题Questionsよくある質問

手机要和电脑连同一个 Wi-Fi 吗？Does my phone need the same Wi-Fi as the computer?スマホとパソコンは同じ Wi-Fi につなぐ必要がありますか？

不用。手机经网关连到电脑，在外面用蜂窝网络也行，也不用开放端口。No. The phone reaches the computer through a gateway, over cellular too, with no open ports.いいえ。スマホはゲートウェイ経由でつながるので、外出先のモバイル回線でも使えます。ポートを開ける必要もありません。

Codex 的账号和 API Key 会经过 LinkShell 吗？Does LinkShell see my Codex sign-in or API key?Codex のアカウントや API キーは LinkShell を経由しますか？

不会。Codex 用电脑上已经登录的那一份运行，LinkShell 不经手账号和密钥。No. Codex runs with the sign-in already on your computer; LinkShell never handles accounts or keys.いいえ。Codex はパソコンでログイン済みのものをそのまま使います。LinkShell がアカウントやキーを扱うことはありません。

能在手机上让 Codex 操作电脑吗？Can Codex use my computer while I watch from the phone?スマホから Codex にパソコンを操作させられますか？

能。用 Computer Use 让 Codex 操作电脑上的浏览器和桌面应用，画面在会话浮窗里实时预览。目前支持 macOS 上的 Codex。Yes. With Computer Use, Codex works the browser and desktop apps on your computer while a floating window shows it live. Codex on macOS for now.はい。Computer Use を使うと、Codex がパソコンのブラウザやデスクトップアプリを操作し、その様子が会話の上のウィンドウにライブで表示されます。現在は macOS の Codex に対応しています。

不打开 App 能批准请求吗？Can I approve a request without opening the app?アプリを開かずにリクエストを承認できますか？

能。iPhone 锁屏的实时活动带「拒绝」和「允许」按钮（iOS 17 及以上），Apple Watch 上也能回复请求（watchOS 10 及以上）。Yes. The Live Activity on the iPhone Lock Screen carries Deny and Allow (iOS 17 or later), and Apple Watch can answer requests too (watchOS 10 or later).はい。iPhone のロック画面のライブアクティビティに「拒否」「許可」ボタンが出ます（iOS 17 以降）。Apple Watch からもリクエストに応答できます（watchOS 10 以降）。
