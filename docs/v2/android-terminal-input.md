# Android 终端字体与语音输入

Android 原生终端随模块打包 JetBrains Mono NL 2.304 的常规、粗体、斜体和粗斜体，避免手机系统替换 `monospace` 后出现不同字形和合成粗体。四种字重保持相同的字符宽度；中文和 emoji 使用 Android 字体回退，Nerd Font 符号继续走原有符号字体。字号设置和缩放范围不变。字体来源与 SIL Open Font License 见 `apps/client/modules/link-terminal/THIRD_PARTY_NOTICES.txt`。

终端的 Android 输入连接使用普通文本编辑器，不再声明可见密码类型。输入法因此可以自行提供语音入口；仍关闭自动建议以免修改命令。中文和语音的中间组合文字留在本地，确认后只向终端提交一次；已提交文字的退格仍发送终端按键。

应用内麦克风按钮通过 `LinkLayout` 调用 Android `SpeechRecognizer`，由手机安装并启用的系统语音服务识别。Android 11 及以后通过 manifest queries 查询该服务。仅在用户点击语音时请求麦克风权限；不再创建只录音、不转文字的 Android 备用录音器，也不会把音频上传到 LinkShell Host 或 Gateway。识别服务是否使用网络由系统服务决定，不承诺离线识别。

识别结果实时更新草稿；自然结束及点击“完成”均保留文字供检查和修改。“插入终端”走既有粘贴流程，不额外附加回车。语音条的发送按钮仍是用户明确结束并发送的操作，它等待最终结果。权限拒绝、缺少识别服务、网络故障和超时有中文提示。取消、应用后台和离开终端都会释放识别会话；取消期间到达的结果不能发送到终端。没有系统识别服务的手机仍可使用自身输入法的语音输入，是否显示入口由输入法决定。

## 验证范围

31 项 JavaScript 相关测试通过，覆盖能力缺失、权限失败、中间与最终结果、自然完成、取消与最终结果竞争、等待权限时取消、错误和后台清理、无识别结果时不发送旧草稿，以及停止失败时不发送中间结果。包含既有终端粘贴、回放和字号测试。字体文件检查确认四种字重的 ASCII 字符宽度均为 600/1000 em。

Android instrumentation 增加普通文本输入类型、组合文字只提交一次、四种字体等宽的检查。当前 Windows 工作环境没有 JDK、Android SDK 或连接的 Android 设备，这些原生测试以及真实手机的字体渲染、输入法和系统语音服务仍需 Android 构建环境验证。JavaScript 测试通过不代表原生验收通过。

本改动包含原生 Kotlin 代码、manifest 和字体资源，需要重新构建并安装 Android 应用；仅更新 JavaScript 不会生效。
