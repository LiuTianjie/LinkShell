# iOS 实时活动

实时活动展示当前电脑的会话与终端摘要。前台与 Host 共用 `packages/wire/src/live-activity.ts` 聚合，`session-attention.ts` 补充前台视图，`LinkLayoutModule.swift` 调用 ActivityKit，`with-live-activity.js` 生成 Widget 扩展。测试输入由 `live-activity-scenarios.test.ts` 从同一聚合函数导出。

## 当前展示

| 场景 | 展示 |
| --- | --- |
| 思考、执行工具、回复 | 绿色波形状态图标，副标题分别显示当前活动 |
| 等待权限确认 | 黄色手掌状态图标，显示授权请求标题 |
| 等待问题回答 | 黄色问答状态图标，显示问题标题 |
| 执行出错 | 红色警告状态图标，显示错误摘要 |
| 多任务 | 最近有进展的活跃任务在前；时间相同时依次看待处理、错误、运行和稳定 ID。头像、标题、正文和详情链接一起切换，状态数量仍汇总所有任务 |
| 终端命令 | 终端图标与命令，计入运行数 |
| 连接断开或内容过期 | 灰色时钟状态图标，提示打开 App 刷新，参与的 Agent 图标变暗，不继续显示旧的执行动作和运行数量 |
| 全部完成、只有未启动或离线会话 | 立即结束活动，不保留一张「已完成」卡片 |

锁屏卡片与灵动岛不展示主机名称或 Agent 类型文字。参与当前任务的 Agent 按类型去重，用略微重叠的官方图标展示，最前面对应当前主任务；锁屏与展开样式最多展示 3 个图标，紧凑样式最多 2 个，超出用 `+N` 表示。旧活动没有 `agents` 字段时使用单个 `agent` 回退。状态仍保留完整的 VoiceOver 描述。

锁屏卡片、灵动岛展开、紧凑和最小样式都读取统一的展示状态。系统的 `ActivityViewContext.isStale` 会覆盖缓存的 phase，因此即使 App 已被挂起、不再同步，也不会把过期内容继续画成绿色运行状态。

iOS 17 及以上在状态变化时替换状态符号，运行活动的副标题变化时触发一次轻量脉冲。头像按稳定标识移动约 0.35 秒，标题与正文约 0.3 秒淡入淡出；减少动态效果或息屏显示时停用这些动效。按照 [WidgetKit 动画规则](https://developer.apple.com/documentation/widgetkit/animating-data-updates-in-widgets-and-live-activities)，动画由数据更新驱动，单次不超过 2 秒，不使用持续循环动画。

## 选项与详情

- iOS 17+ 的锁屏和灵动岛展开态，最多显示 3 个完整的权限/单选按钮。优先展示“拒绝 / 允许 / 本会话都允许”等实际选项；不擅自推断默认操作。
- 整行放不下时显示“查看全部选项”；标题始终可打开对应电脑的任务详情。多选、多问题表单、敏感输入和网页授权都在详情中完成。iOS 16.x 使用详情入口。
- 按钮采用 `Button(intent:)` 和 `LiveActivityIntent`。点击后按系统要求解锁并唤起 App，App 自动提交所选操作，再打开详情，不需要重新点一次选项。
- 选择先写入原生的一次性队列，外部 URL 只能打开详情或消费已存在的队列 ID，不能凭 URL 参数伪造批准。队列有过期与重复点击保护；App 等待正确电脑在线并读到最新请求后，再核对请求 ID 和选项。连接失败或结果不确定时不自动重放操作。
- 内容过期后隐藏按钮，避免使用陈旧请求。

## 后台边界

iOS 可以挂起后台 JS，手机定时器、WebSocket 重连和 Background Fetch 都不能保证持续刷新。静音音频循环及其后台音频声明已移除。

正式构建可以打开 ActivityKit/APNs 远程更新：App 前台创建活动、交接 token 和单活动授权；Host 独立观察任务，通过 `push.itool.tech` 更新活动。服务代码、注册、轮换、结束与重启恢复已接入，仍需生产 Key 和签名构建才能验证投递。只做实时活动，不接友盟或传统通知，详见 [配置和准备清单](live-activity-push.md)。

授权交接完成后，原生层不会因为手机退到后台或本地 socket 断开，把服务端更新的卡片覆盖成离线。`staleDate` 表示最后一次有效更新的新鲜度；3 分钟收不到更新时显示过期提示，而不是断言电脑已经离线。APNs 仍由系统调度，不保证逐帧或无限期刷新。

开源构建默认不启用远程服务，保留前台本地更新；App 被挂起后可自然过期。有任务时 JS 的 60 秒同步仅在运行时获得执行机会时生效。所有任务结束时结束活动。

## 验证与交付

- 叠放头像、按钮、溢出和切换动效使用生产 SwiftUI 视图在独立 iPhone Air / iOS 26.5 模拟器中渲染。它们是原生视图预览，不等同于系统锁屏 App Intent 点击或完整 App 的远程交互验证。
- 聚合与选项测试覆盖最近进展排序、时间相同的稳定顺序、终端数量、选项变化、过期和跨电脑请求。原生队列检查覆盖冷启动、重复消费、过期和有界存储。
- Host 与服务测试使用本地 HTTP 和模拟 APNs，覆盖手机断开后订阅保留、Host 重启、退避后的最新快照、授权隔离、撤销竞态、乱序、结束、JWT 签名和 4 KB 大小限制。没有真实 Key，因此不证明生产投递。
- Widget 源码和原生方法的变更需要新的 iOS 二进制；CLI 更新或 Metro 重载不能更新已安装的 Widget。
